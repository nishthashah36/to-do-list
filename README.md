# Floral Todo

A light pink-and-blue personal to-do app with three priority levels, optional due dates, categories, and offline support.

## Publish with GitHub Pages

1. Upload `index.html`, `styles.css`, `app.js`, `manifest.json`, `service-worker.js`, and `icon.svg` to the repository root.
2. Open **Settings → Pages** in the GitHub repository.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main`, choose `/ (root)`, and save.
5. Open the published address shown by GitHub.

## Add to iPhone

Open the published app in Safari, tap **Share**, select **Add to Home Screen**, and tap **Add**.

Tasks are stored locally on that browser/device. Clearing Safari website data or deleting the home-screen app can erase them.
